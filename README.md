   - suivre les évolutions du métier de Data Analyst ;
   - identifier les outils et méthodes les plus utilisés ;
   - observer les compétences recherchées dans les offres d'emploi.

2. **Sources**
   - documentations officielles ;
   - blogs techniques ;
   - offres d'emploi ;
   - communautés professionnelles ;
   - newsletters et publications spécialisées.

3. **Méthode de sélection**
   - fiabilité de la source ;
   - récence ;
   - pertinence pour le métier ;
   - applicabilité aux projets.

4. **Résultats de la veille**
   - outils identifiés ;
   - méthodes retenues ;
   - changements apportés à ma pratique ou à mes projets.
